# Index terms for the Nyctos document.
#
# One entry per line:
#
#     Display Name = pattern|pattern|pattern
#
# The right-hand side is a lowercase Lua pattern matched against each block
# with a word boundary either side. Omit it and the display name is used,
# lowercased. Comments and blank lines are ignored.
#
# Lua patterns are not regular expressions: there is no alternation inside a
# pattern, which is what the "|" separated list is for, and "-" is a modifier
# rather than a literal, so a hyphen must be written inside a set as [-].
#
# A term earns a section if it appears there more than once, or appears in one
# of its headings, or occurs in that section and nowhere else. No entry keeps
# more than five references, and the heaviest section is set bold. Code blocks
# are not counted, so section 23 does not swamp the prose.
#
# The list is deliberately in two halves. Terminology particular to Nyctos is
# what a reader cannot look up anywhere else and has to be able to find here.
# Standard operating system terminology is indexed only where this document
# says something specific about it, which is why "scheduler" is absent and
# "cohort scheduling node" is present.
